# Учебный проект для NUCLEO-G474RE c использованием ОСРВ Zephyr

Данный проект создан для изучения возможностей операционной системы реального 
времени Zephyr. Для создания проекта использовалось расширение IDE for Zephyr (VSCode).

## Подключение к shell

Для взаимодействия с shell используется адаптер USB-UART, подключаемый по схеме:

| Адаптер | NUCLEO-G474RE |
---------------------------
| RX      | PA9           |
| TX      | PA10          |
| GND     | GND           |

Настройки подключения:

- Скорость: 115200
- Количество бит: 8
- Паритет: нет
- Стоп-биты: 1
- Контроль потока: нет
