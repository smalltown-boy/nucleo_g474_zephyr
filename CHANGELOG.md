# История изменений

## [0.1.0] - 28.10.2026

### Добавлено:

- В shell была добавлена команда ```task```, которая осуществляет вызов команды ```kernel``` с
 аргументами ```thread``` и ```list```. В результате в консоль выводится информация о всех 
 действующих потоках и их свойствах.
- Создана ничего не делающая задача ```simply_task```.



## [0.1.1] - 28.10.2026

### Добавлено:

- Созданы файлы ```README.md``` и ```CHANGELOG.md```.



## [0.1.2] - 28.10.2026

### Добавлено:

- Добавлена команда ```led``` для управления светододом на плате ```NUCLEO-G474RE```

### Изменено:

- Исправлено оформление таблицы в файле ```README.md```
